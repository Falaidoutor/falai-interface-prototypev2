Sobre o projeto

FalAI Doutor

O FalAI Doutor é um protótipo de interface para triagem médica com apoio de inteligência artificial. A proposta é facilitar o primeiro contato do paciente, organizar sintomas e apoiar equipes de saúde na priorização dos atendimentos.

O projeto combina uma experiência simples para pacientes com uma área médica voltada para acompanhamento de casos, consulta de detalhes e tomada de decisão.

Objetivo

Criar uma solução acadêmica que demonstre como sistemas digitais podem melhorar fluxos de triagem, reduzindo ruídos na coleta inicial de informações e trazendo mais clareza para profissionais de saúde.
